Betting Score Tiers

What each level means · Shared CFB + NFL ladder · Entertainment / analysis only

Betting Score is 1–99 measuring strength of betting interest / edge, not how sure we are of the final score. There is no score of 100 — no guaranteed Locks, never 100% confidence in a game. The same game gets the same score on the Daily Menu and the Report. Higher tiers mean stronger interest — always read the Report Bottom line for Play (or No bet).

Ignore Weak Playable Strong Prime Lock
TierRangeWhat it means
Ignore 1–49 A pass. Little or no betting edge vs the number. Expect Stay away / No bet on the Bottom line.
Weak 50–59 Soft interest only. Something mild is there, but not enough to lean hard. Fine to watch the line; usually not enough to treat as a play by itself.
Playable 60–69 Real candidate. The matchup clears the bar for a serious look. Interesting enough to dig into — not an automatic play. Read the Report before deciding.
Strong 70–79 Clear edge with real evidence behind it. This is a normal high-interest board game when the number fits. Still check injuries, price, and the Report Bottom line.
Prime 80–89 Top-shelf interest. Several signals line up (models, injuries, market, situation). Uncommon. We run an extra honesty check before publishing this tier.
Lock 90–99 Best-of-board rare. Strong, well-documented edge and the number still looks available. Expect this infrequently — treat it as exceptional, not everyday. Ceiling is 99 on purpose.

Keep the signals separate

  • Final Score Confidence (Low / Medium / High) is separate — it is about the projected final score, not Betting Score.
  • Scores are earned from evidence; higher tiers are not handed out by calendar.
  • Entertainment / analysis only — not financial or betting advice. Paper bankrolls only.

Use the tier to frame the research, not to skip it.
